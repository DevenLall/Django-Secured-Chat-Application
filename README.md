# Secured-Chat-Application

secured chat application that will include cruds, real time chat with multiple users with authentication and authorization

# Features Available

- Login/signup with email verification
- User profiles with avatars
- 1-on-1 direct messages andgroup chat rooms
- Real-time messaging via WebSockets
- User search to find and message people
- Encrypted transport via SSL certificates

# The Tech Stack

- **Django**
- **django-allauth**
- **Django Channels and channels-redis**
- **Redis**
- **Docker**
- **Uvicorn**
- **mkcert**
